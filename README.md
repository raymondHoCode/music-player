# 🎵 Music Player App

A modern web-based music player built with React. Create playlists, search songs, and manage your music in a clean and interactive UI. Try not to vibe code challenge so I can learn react [other than for comments or the readme]

---

## 🚀 Features

* 🎶 Create and manage playlists
* 🔍 Search songs by title or artist
* ➕ Add songs to playlists
* 🗑️ Remove playlists (optional if implemented)
* 📂 View songs inside each playlist
* ⚡ Fast and responsive UI

---

## 🛠️ Tech Stack

* React
* JavaScript (ES6+)
* Vite
* CSS

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/music-player.git
cd music-player
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🧠 How It Works

* Uses React Context (`MusicContext`) to manage global state
* Playlists are stored in state and updated dynamically
* Songs can be added to playlists without duplication
